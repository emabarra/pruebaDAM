## 📖 Sobre el Proyecto

Esta aplicación móvil para el sistema operativo Android fue desarrollada para **CENAMAD** (*Centro Nacional de Excelencia para la Industria de la Madera*).
Su objetivo principal es el poder difundir noticias, proyectos de investigación e innovación científica en torno a la industria de la madera en Chile.
Además de transparentar su visión, equipos de trabajos, indicadores de logros, aportantes y alianzas tanto del mundo privado y publico.

---

## Características Principales
* 📰 **Sección de Noticias y Proyectos:** Publicaciones y actualizaciones de novedades del centro.
* 👤 **Sección de los equipos de trabajos:** Transparencia de quienes conforman los diferentes equipos de trabajos del centro.
* 🤳🏻 **Interfaz intuitiva:** Diseño responsive optimizado para dispositivos móviles Android.
* 📋 **Qué es CENAMAD:** Sección exclusiva para su misión y visión.

## 🚀 Instalación y Configuración Local

Para clonar y ejecutar esta aplicación en tu entorno local, sigue estos pasos:
1. **Clonar el repositorio:**
  ```bash
  git clone https://github.com/emabarra/pruebaDAM.git
  ```

2. **Abrir el proyecto:**
   Abre Android Studio, y abre la carpeta del proyecto clonado.

3. **Sincronizar dependencias:**
   Deja que Gradle descargue las dependencias necesarias.

4. **Ejecutar App:**
   Conecta un dispositivo físico vía USB (con depuración USB activa) o inicia un emulador Android (AVD) y presiona
   ```bash
   Run (Shift + F10)
   ```
